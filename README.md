# SKILL

A collection of reusable Copilot skills.

## Installation

### Global (all workspaces)

```bash
mkdir -p ~/.agents/skills
cp -r ./skills/<skill-name> ~/.agents/skills/
```

### Workspace only

```bash
mkdir -p <workspace-root>/.agents/skills
cp -r ./skills/<skill-name> <workspace-root>/.agents/skills/
```
